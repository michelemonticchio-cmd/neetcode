# NeetCode 150

My solutions to the [NeetCode 150](https://neetcode.io/practice) problems, in **Java** and **Python**.

## Structure

- `java/` — Maven project with Java solutions and JUnit tests
- `python/` — Python solutions with pytest tests
- `scripts/` — utility scripts (e.g. to scaffold a new problem)

Each problem has its own folder with a `Solution` file, a `README.md` with the approach and complexity analysis, and tests.

## Workflow

For each problem:
1. Solve it on [NeetCode](https://neetcode.io/practice) or [LeetCode](https://leetcode.com/)
2. Copy the solution into the corresponding folder in this repo
3. Write a brief analysis (approach and complexity) in the problem's `README.md`
4. Add JUnit / pytest tests with a few representative cases
5. Update the table above (⬜ → ✅) and the progress counter
6. Commit with format: `add: NNNN Problem Name (category)`
