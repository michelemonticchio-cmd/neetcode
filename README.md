# NeetCode 150

My solutions to the [NeetCode 150](https://neetcode.io/practice) problems, in **Java** and **Python**.

## Structure

- `java/` — Maven project with Java solutions and JUnit tests
- `python/` — Python solutions with pytest tests
- `scripts/` — utility scripts (e.g. to scaffold a new problem)

Each problem has its own folder with a `Solution` file, a `README.md` with the approach and complexity analysis, and tests.
